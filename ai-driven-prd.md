Спецификация продукта (PRD): Лендинг с AI-квизом и AI-чатом для квалификации лидов


1. Обзор проекта и Технологический стек

• Цель: Высококонверсионный лендинг с адаптивным ИИ-квизом и плавающим ИИ-ассистентом продаж для автоматического скоринга и квалификации лидов.
• Главный KPI: Сбор 4 ключевых метрик клиента по методологии BANT (Бюджет, Потребность, Сроки, Контакты) и отправка данных через Webhook в CRM.
• Стек технологий:
 • Frontend: React (Vite) + Tailwind CSS + Lucide Icons / Shadcn UI.
 • Управление состоянием: React Context или Zustand (легковесный и надежный для хранения шагов квиза и логов чата).
 • Интеграция с ИИ: OpenAI API (модель gpt-4o-mini) / Vercel AI SDK ИЛИ клиентский Mock-режим (имитация ответов ИИ) для локального тестирования без ключей.

3. Функциональные требования к компонентам


3.1. Интерфейс лендинга (Landing Layout)

• Главный экран (Hero Section): Минималистичный премиальный UI. Четкое УТП. Две фокусные кнопки призыва к действию (CTA): [ Запустить AI-расчет ] (открывает модальное окно квиза) и [ Задать вопрос ИИ-ассистенту ] (разворачивает виджет чата).
• Стиль: Современная темная/светлая тема (Slate/Zinc палитра), плавные анимации появления элементов.

3.2. Модуль А: Интерактивный квиз (/components/Quiz)

• Логика: Пошаговая динамическая форма с индикатором прогресса сверху.
• Шаги квиза:
 1. Сегмент бизнеса / Ниша (Выбор карточек с иконками).
 2. Текущий бюджет (Ползунок или выбор диапазонов цен).
 3. Срочность задачи (Варианты: «Вчера», «В течение месяца», «Просто изучаю рынок»).
 4. Главная боль / Цель (Текстовое поле ввода или чекбоксы).
 5. Форма захвата (Имя, Телефон или Telegram). Блокировать отправку и расчет, пока не введены валидные контакты.

3.3. Модуль Б: AI Chat Assistant (/components/AIChat)

• UI: Круглая плавающая кнопка-баббл в правом нижнем углу. По клику открывается лаконичное окно чата. Должна быть анимация «ИИ печатает...» (Typing Indicator).
• Системный промпт для BANT-квалификации (Инструкция для ИИ в коде):
text
Ты — "LeadBot", экспертный ИИ-менеджер по продажам. Твои цели:
1. Быстро и точно отвечать на вопросы пользователя о продуктах компании на основе базы знаний.
2. Ненавязчиво внедрять в диалог встречные вопросы для квалификации по BANT:
   - Каков бюджет проекта?
   - Какая конкретно бизнес-задача стоит?
   - В какие сроки нужно реализовать?
3. Как только параметры определены, мягко запроси Телефон или Telegram для связи с экспертом.
4. Ответы должны быть короткими — не более 3 предложений. Тон: деловой, дружелюбный, нацеленный на конверсию.
Используйте код с осторожностью.
